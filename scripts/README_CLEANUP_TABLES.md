# Скрипт очищення невикористаних таблиць

Цей скрипт аналізує структуру проекту, знаходить всі таблиці, які використовуються в коді, і видаляє ті таблиці з бази даних, які не використовуються.

## Вимоги

1. Python 3.8+
2. Встановлені залежності:
   ```bash
   pip install supabase psycopg2-binary loguru
   ```

## Налаштування

### Варіант 1: Використання DATABASE_URL (рекомендовано)

Додайте до `.env` файлу в корені проекту або в `apps/backend/.env`:

```env
DATABASE_URL=postgresql://postgres:[PASSWORD]@[HOST]:[PORT]/postgres
```

Або для Supabase:

```env
DATABASE_URL=postgresql://postgres.xxxxx:[PASSWORD]@aws-0-eu-central-1.pooler.supabase.com:6543/postgres
```

Connection string можна знайти в Supabase Dashboard:
- Settings → Database → Connection string → Connection pooling

### Варіант 2: Використання Supabase Service Key

Якщо `DATABASE_URL` не вказано, скрипт спробує використати Supabase client з налаштувань проекту (потребує `SUPABASE_URL` та `SUPABASE_SERVICE_KEY`).

## Використання

### Запуск скрипта

```bash
# З кореня проекту
python scripts/cleanup_unused_tables.py

# Або з директорії scripts
cd scripts
python cleanup_unused_tables.py
```

### Що робить скрипт

1. **Сканує код проекту** - знаходить всі таблиці, які використовуються в коді:
   - Пошук `.table("table_name")` в Python коді
   - Пошук SQL запитів (FROM, JOIN, UPDATE, DELETE)
   - Аналіз TypeScript/JavaScript файлів

2. **Отримує список таблиць з БД**:
   - Через `psycopg2` (якщо `DATABASE_URL` доступний)
   - Або через Supabase client (fallback)

3. **Порівнює списки**:
   - Знаходить таблиці, які є в БД, але не використовуються в коді
   - Виключає системні таблиці Supabase

4. **Видаляє невикористані таблиці**:
   - З підтвердженням користувача
   - Або генерує SQL скрипт для ручного виконання

## Безпека

- Скрипт **завжди** запитує підтвердження перед видаленням
- Використовує `DROP TABLE IF EXISTS ... CASCADE` для безпечного видалення
- Не видаляє системні таблиці Supabase
- Можна запустити в dry-run режимі (просто скасувати підтвердження)

## Системні таблиці

Скрипт автоматично виключає системні таблиці Supabase:
- `schema_migrations`
- `supabase_migrations`
- `storage.objects`
- `storage.buckets`
- `auth.*` таблиці
- `realtime.*` таблиці

## Troubleshooting

### Помилка: "DATABASE_URL не знайдено"

**Рішення:** Додайте `DATABASE_URL` до `.env` файлу або використайте Supabase connection string.

### Помилка: "psycopg2 не встановлено"

**Рішення:**
```bash
pip install psycopg2-binary
```

### Помилка: "Не вдалося автоматично отримати список таблиць"

**Рішення:**
1. Перевірте, чи правильно налаштований `DATABASE_URL`
2. Або виконайте SQL запит вручну в Supabase SQL Editor:
   ```sql
   SELECT table_name
   FROM information_schema.tables
   WHERE table_schema = 'public'
   AND table_type = 'BASE TABLE'
   ORDER BY table_name;
   ```

### Скрипт не знаходить таблиці в коді

**Рішення:** Перевірте, чи таблиці використовуються через `.table()` метод або SQL запити. Якщо таблиці використовуються іншим способом, додайте їх вручну до списку використаних таблиць в коді скрипта.

## Примітки

- Скрипт аналізує тільки файли в `apps/backend/`
- Шукає таблиці в файлах: `.py`, `.ts`, `.tsx`, `.js`, `.jsx`, `.sql`
- Використовує regex для пошуку використання таблиць
- Може не знайти таблиці, які використовуються динамічно

## Автоматизація

Для автоматичного запуску (наприклад, в CI/CD), можна модифікувати скрипт, щоб він приймав аргумент `--yes` для автоматичного підтвердження:

```bash
python scripts/cleanup_unused_tables.py --yes
```

(Ця функціональність поки не реалізована, але може бути додана за потреби)
