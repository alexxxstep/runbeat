# Міграція: Додавання genres та interval_stages до таблиці workouts

## Виконання міграції

1. Відкрийте [Supabase SQL Editor](https://supabase.com/dashboard)
2. Виберіть ваш проект
3. Натисніть **"New query"**
4. Скопіюйте та виконайте SQL з файлу `apps/backend/DATABASE_MIGRATION_ADD_GENRES_AND_STAGES.sql`

## Що додається

- **`genres`** (TEXT[]) - Масив жанрів музики, вибраних для воркаута
- **`interval_stages`** (JSONB) - JSON масив етапів інтервального тренування з полями:
  - `name` - Назва етапу
  - `duration_minutes` - Тривалість в хвилинах
  - `hr_zone` - Діапазон частоти серцебиття [min, max]
  - `bpm_range` - Діапазон BPM [min, max]

## Переваги

✅ Всі параметри воркаута зберігаються для повторного використання
✅ При активації існуючого воркаута використовуються збережені жанри та етапи
✅ Консистентність: плейлисти генеруються з тими ж параметрами, що були при створенні воркаута
