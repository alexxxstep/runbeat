# Які дані парсить асистент з чату

**Дата:** 2025-11-14

---

## 📋 Структура WorkoutIntent

Асистент парсить повідомлення користувача в структурований об'єкт `WorkoutIntent`:

```python
class WorkoutIntent(BaseModel):
    # Обов'язкові поля
    workout_type: Literal["continuous", "intervals", "fartlek", "recovery"]
    duration_minutes: int  # 5-180 хвилин
    target_bpm_min: int    # 80-200 BPM
    target_bpm_max: int    # 80-200 BPM
    confidence: float      # 0.0-1.0

    # Опціональні поля
    intervals: Optional[List[IntervalPhase]]  # Для interval/fartlek workouts
    energy_profile: Literal["steady", "building", "wave"]  # За замовчуванням: "steady"
    mood: Optional[str]  # Емоційний контекст тренування

    # 🎵 НОВІ ПОЛЯ: Музичні побажання
    music_genres: Optional[List[str]]  # Жанри музики (наприклад: ["rock", "electronic"])
    music_prompt: Optional[str]  # Опис стилю/настрою музики (наприклад: "мотивуюча музика")

    # Поля для уточнення
    needs_clarification: bool  # Чи потрібне уточнення
    clarification_question: Optional[str]  # Питання для уточнення
```

---

## 🔍 Детальний опис полів

### 1. workout_type (обов'язкове)

**Тип тренування:**

- `"continuous"` - Стабільна пробіжка (steady run)
- `"intervals"` - Інтервальна пробіжка (interval training)
- `"fartlek"` - Фартлек (шведська гра швидкостей)
- `"recovery"` - Відновлювальна пробіжка

**Приклади розпізнавання:**
- "хочу побігати" → `continuous`
- "інтервали" → `intervals`
- "фартлек" → `fartlek`
- "відновлення" → `recovery`

---

### 2. duration_minutes (обов'язкове)

**Тривалість тренування в хвилинах:** 5-180 хвилин

**Приклади розпізнавання:**
- "30 хв" → `30`
- "півгодини" → `30`
- "1 година" → `60`
- "45 хвилин" → `45`
- "2 години" → `120`

---

### 3. target_bpm_min / target_bpm_max (обов'язкові)

**Діапазон BPM (ударів на хвилину):** 80-200 BPM

**Як визначається:**
AI мапить інтенсивність на BPM діапазони:

| Інтенсивність | Ключові слова | BPM діапазон |
|--------------|---------------|--------------|
| **Low** | "легкий", "легкому", "easy", "recovery", "відновлення" | 110-130 BPM |
| **Moderate** | "темповий", "tempo", "помірний", "moderate" | 130-160 BPM |
| **High** | "швидкий", "fast", "інтервали", "intervals", "висока" | 160-180 BPM |

**Приклади:**
- "легкий біг" → `target_bpm_min: 110, target_bpm_max: 130`
- "темповий біг" → `target_bpm_min: 140, target_bpm_max: 160`
- "інтервали" → `target_bpm_min: 160, target_bpm_max: 180`

---

### 4. intervals (опціональне)

**Інтервальні фази:** Потрібно тільки для `intervals` та `fartlek` workouts

```python
class IntervalPhase(BaseModel):
    type: Literal["work", "rest"]  # Робота або відпочинок
    duration_minutes: int  # 1-60 хвилин
    target_bpm: int  # 80-200 BPM
```

**Приклади розпізнавання:**
- "5-2" → `work: 5 min, rest: 2 min`
- "3 хв робота, 1 хв відпочинок" → `work: 3 min, rest: 1 min`
- "10x400м" → `work: ~2 min, rest: ~1 min` (припущення)

---

### 5. energy_profile (опціональне)

**Профіль енергії:**

- `"steady"` - Стабільна енергія (за замовчуванням)
- `"building"` - Наростаюча енергія
- `"wave"` - Хвильова енергія (для інтервалів)

**Приклади:**
- "стабільний біг" → `steady`
- "прогресивний біг" → `building`
- "інтервали" → `wave`

---

### 6. mood (опціональне)

**Емоційний контекст тренування:**

**Приклади:**
- "енергійне тренування" → `mood: "energetic"`
- "спокійний біг" → `mood: "calm"`
- "агресивне тренування" → `mood: "aggressive"`

---

### 7. music_genres (опціональне) 🎵 НОВЕ

**Жанри музики:** Список жанрів, які користувач хоче слухати

**Розпізнавані жанри:**
- "рок", "rock"
- "електроніка", "electronic"
- "хіп-хоп", "hip-hop"
- "поп", "pop"
- "метал", "metal"
- "техно", "techno"
- "хаус", "house"
- "джаз", "jazz"
- "класика", "classical"
- та інші

**Приклади розпізнавання:**
- "під рок-музику" → `music_genres: ["rock"]`
- "хіп-хоп та електроніку" → `music_genres: ["hip-hop", "electronic"]`
- "техно і хаус" → `music_genres: ["techno", "house"]`

---

### 8. music_prompt (опціональне) 🎵 НОВЕ

**Опис стилю/настрою музики:** Текстовий опис бажаної музики

**Приклади розпізнавання:**
- "мотивуюча музика" → `music_prompt: "мотивуюча музика"`
- "агресивний рок" → `music_prompt: "агресивний"`
- "спокійна електроніка" → `music_prompt: "спокійна"`
- "енергійна" → `music_prompt: "енергійна"`
- "ритмічна" → `music_prompt: "ритмічна"`
- "під біт" → `music_prompt: "під біт"`
- "з басами" → `music_prompt: "з басами"`

**Якщо користувач вказує і жанр, і опис:**
- "під рок-музику, агресивну" → `music_genres: ["rock"], music_prompt: "агресивна"`

---

### 9. confidence (обов'язкове)

**Впевненість AI в розпізнаванні:** 0.0-1.0

**Критерії:**
- `0.9+` - Висока впевненість (всі дані чітко вказані)
- `0.7-0.9` - Середня впевненість (більшість даних є)
- `0.6-0.7` - Помірна впевненість (деякі дані відсутні)
- `<0.6` - Низька впевненість (потрібне уточнення)

**Приклади:**
- "30 хв легкий біг" → `confidence: 0.95` (всі дані є)
- "хочу побігати" → `confidence: 0.4` (немає тривалості та інтенсивності)

---

### 10. needs_clarification (обов'язкове)

**Чи потрібне уточнення:** `true` / `false`

**Коли `true`:**
- Відсутні критичні дані (тривалість, інтенсивність)
- Низька впевненість (`confidence < 0.6`)
- Для інтервалів - відсутній патерн інтервалів

**Коли `false`:**
- Всі критичні дані є
- Висока впевненість (`confidence >= 0.9`)
- Або помірна впевненість (`0.6-0.7`), але всі обов'язкові поля присутні

---

### 11. clarification_question (опціональне)

**Питання для уточнення:** Текст питання, якщо потрібне уточнення

**Приклади:**
- "Скільки часу плануєш бігти?"
- "Яка інтенсивність - легкий біг, темповий чи інтервали?"
- "Який буде інтервал роботи/відпочинку?"

## 🎯 Як AI розпізнає дані

### 1. Тип тренування

AI шукає ключові слова:
- "інтервали", "intervals" → `intervals`
- "фартлек", "fartlek" → `fartlek`
- "відновлення", "recovery" → `recovery`
- За замовчуванням → `continuous`

### 2. Тривалість

AI розпізнає:
- Числа з одиницями: "30 хв", "1 година"
- Слова: "півгодини" → 30, "година" → 60
- Контекст: "довгий біг" → ~60-90 хв

### 3. Інтенсивність → BPM

AI мапить інтенсивність на BPM:
- "легкий" → Zone 1-2 (110-130 BPM)
- "темповий" → Zone 2-3 (130-160 BPM)
- "інтенсивне" → Zone 4-5 (160-180 BPM)

### 4. Жанри музики 🎵

AI розпізнає жанри:
- Прямі згадки: "рок", "rock", "електроніка"
- Контекст: "під рок-музику" → `["rock"]`
- Кілька жанрів: "хіп-хоп та електроніку" → `["hip-hop", "electronic"]`

### 5. Опис музики 🎵

AI розпізнає описи:
- "мотивуюча", "мотивуючу" → `"мотивуюча музика"`
- "агресивна", "агресивний" → `"агресивна"`
- "спокійна" → `"спокійна"`
- "енергійна" → `"енергійна"`
- "ритмічна" → `"ритмічна"`

|------|---------|-----|---------------|

## ✅ Висновок

**Асистент парсить з чату:**

1. ✅ **Тип тренування** (continuous/intervals/fartlek/recovery)
2. ✅ **Тривалість** (5-180 хвилин)
3. ✅ **Інтенсивність** (мапиться на BPM діапазон)
4. ✅ **Інтервали** (для interval/fartlek workouts)
5. ✅ **Профіль енергії** (steady/building/wave)
6. ✅ **Настрій** (опціонально)
7. ✅ **Жанри музики** 🎵 (список жанрів)
8. ✅ **Опис музики** 🎵 (текстовий опис стилю/настрою)
9. ✅ **Впевненість** (0.0-1.0)
10. ✅ **Потреба в уточненні** (true/false)
11. ✅ **Питання для уточнення** (якщо потрібно)

**Всі ці дані зберігаються в workout при створенні!**
