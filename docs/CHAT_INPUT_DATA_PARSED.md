# Які дані парсить асистент з чату

**Дата:** 2025-11-14

---

## 📋 Повний список полів, які парсяться з повідомлення користувача

Асистент парсить повідомлення користувача та витягує наступні дані в структуру `WorkoutIntent`:

---

## 🏃 Параметри тренування (обов'язкові)

### 1. `workout_type` (тип тренування)
**Тип:** `"continuous" | "intervals" | "fartlek" | "recovery"`

**Що парсить:**
- Тип тренування з повідомлення
- Ключові слова: "інтервали", "фартлек", "відновлення", "стабільна", "темпова"

**Приклади:**
- "інтервали" → `"intervals"`
- "фартлек" → `"fartlek"`
- "відновлення" → `"recovery"`
- "стабільна пробіжка" → `"continuous"`

---

### 2. `duration_minutes` (тривалість)
**Тип:** `int` (5-180 хвилин)

**Що парсить:**
- Тривалість тренування в хвилинах
- Розпізнає формати: "30 хв", "1 година", "45 хвилин"

**Приклади:**
- "30 хв" → `30`
- "1 година" → `60`
- "45 хвилин" → `45`

---

### 3. `target_bpm_min` та `target_bpm_max` (діапазон BPM)
**Тип:** `int` (80-200 BPM)

**Що парсить:**
- Діапазон BPM на основі інтенсивності
- Автоматично визначається з інтенсивності, якщо не вказано явно

**Маппінг інтенсивності:**
- Легка → 110-130 BPM
- Помірна → 130-160 BPM
- Висока → 160-180 BPM

---

## ⚡ Параметри інтенсивності

### 4. `energy_profile` (енергетичний профіль)
**Тип:** `"steady" | "building" | "wave"` (за замовчуванням: `"steady"`)

**Що парсить:**
- Профіль енергії тренування
- Автоматично визначається з типу тренування

---

### 5. `mood` (настрій)
**Тип:** `string | null` (опціонально)

**Що парсить:**
- Емоційний контекст тренування
- Ключові слова: "енергійний", "спокійний", "агресивний"

**Приклади:**
- "енергійне тренування" → `"energetic"`
- "спокійний біг" → `"calm"`

---

## 🎵 Музичні побажання (нові поля)

### 6. `music_genres` (жанри музики)
**Тип:** `List[str] | null` (опціонально)

**Що парсить:**
- Жанри музики, згадані в повідомленні
- Розпізнає жанри українською та англійською

**Підтримувані жанри:**
- "рок", "rock"
- "електроніка", "electronic"
- "хіп-хоп", "hip-hop"
- "поп", "pop"
- "метал", "metal"
- "техно", "techno"
- "хаус", "house"
- "джаз", "jazz"
- "класика", "classical"
- та інші

**Приклади:**
- "під рок-музику" → `["rock"]`
- "хіп-хоп та електроніку" → `["hip-hop", "electronic"]`
- "техно і хаус" → `["techno", "house"]`

---

### 7. `music_prompt` (опис музики)
**Тип:** `string | null` (опціонально)

**Що парсить:**
- Опис стилю, настрою або характеристик музики
- Розпізнає описові слова про музику

**Ключові слова:**
- "мотивуюча", "мотивуючу" → `"мотивуюча музика"`
- "агресивна", "агресивний" → `"агресивна"`
- "спокійна" → `"спокійна"`
- "енергійна" → `"енергійна"`
- "ритмічна" → `"ритмічна"`
- "під біт" → `"під біт"`
- "з басами" → `"з басами"`
- "мелодійна" → `"мелодійна"`

**Приклади:**
- "мотивуюча музика" → `"мотивуюча музика"`
- "агресивний рок" → `"агресивна"` (якщо є genre, то prompt окремо)
- "спокійна електроніка" → `"спокійна"`

---

## 🔄 Інтервали (для interval та fartlek тренувань)

### 8. `intervals` (фази інтервалів)
**Тип:** `List[IntervalPhase] | null` (опціонально)

**Що парсить:**
- Структуру інтервалів (робота/відпочинок)
- Тривалість кожної фази
- BPM для кожної фази

**Структура IntervalPhase:**
```python
{
  "type": "work" | "rest",
  "duration_minutes": int (1-60),
  "target_bpm": int (80-200)
}
```

**Приклади:**
- "5-2" (5 хв робота, 2 хв відпочинок) → парситься як два інтервали
- "3 хв робота, 1 хв відпочинок" → парситься як два інтервали

---

## 📊 Метадані парсингу

### 9. `confidence` (впевненість)
**Тип:** `float` (0.0-1.0)

**Що парсить:**
- Рівень впевненості в правильності парсингу
- Високий (0.9+) коли всі дані чітко вказані
- Низький (<0.7) коли дані невизначені

---

### 10. `needs_clarification` (потрібне уточнення)
**Тип:** `bool`

**Що парсить:**
- Чи потрібно уточнити дані у користувача
- `true` якщо не вистачає критичних параметрів
- `false` якщо всі дані є

---

### 11. `clarification_question` (питання для уточнення)
**Тип:** `string | null` (опціонально)

**Що парсить:**
- Питання для уточнення, якщо `needs_clarification = true`
- Генерується автоматично на основі відсутніх даних

**Приклади:**
- "Скільки часу плануєш бігти?"
- "Яка інтенсивність - легкий біг, темповий чи інтервали?"
- "Який буде інтервал роботи/відпочинку?"

## 🎯 Як працює парсинг

### 1. Крок 1: Отримання повідомлення
```typescript
// Frontend відправляє
POST /api/v1/chat/message
{
  "message": "30 хв інтервалів під рок-музику",
  "user_id": "user-123",
  "conversation_id": "conv-456"
}
```

### 2. Крок 2: Парсинг через AI
```python
# Backend викликає LLMService
intent = await llm_service.parse_workout(
    user_message="30 хв інтервалів під рок-музику",
    conversation_state=conversation_state
)
```

### 3. Крок 3: AI аналізує повідомлення
- Розпізнає ключові слова
- Визначає тип тренування
- Витягує тривалість
- Визначає інтенсивність → BPM
- **Витягує жанри музики** (якщо згадані)
- **Витягує опис музики** (якщо згаданий)

### 4. Крок 4: Повернення структурованого результату
```python
# WorkoutIntent об'єкт з усіма полями
WorkoutIntent(
    workout_type="intervals",
    duration_minutes=30,
    target_bpm_min=160,
    target_bpm_max=180,
    music_genres=["rock"],  # ← Парситься з повідомлення
    music_prompt=None,
    confidence=0.85,
    needs_clarification=True
)
```

## 🔍 Детальний опис полів

### Обов'язкові поля (завжди присутні)
1. ✅ `workout_type` - тип тренування
2. ✅ `duration_minutes` - тривалість
3. ✅ `target_bpm_min` - мінімальний BPM
4. ✅ `target_bpm_max` - максимальний BPM
5. ✅ `energy_profile` - профіль енергії
6. ✅ `confidence` - впевненість
7. ✅ `needs_clarification` - потрібне уточнення

### Опціональні поля (можуть бути null)
8. ⚪ `intervals` - фази інтервалів
9. ⚪ `mood` - настрій
10. ⚪ `music_genres` - **жанри музики** (нове поле)
11. ⚪ `music_prompt` - **опис музики** (нове поле)
12. ⚪ `clarification_question` - питання для уточнення
