# Чеклист для ручного тестування RunBeat

## 🎯 Інструкції

Використовуйте цей чеклист для послідовного тестування всіх функцій додатку.

---

## ✅ 1. Авторизація та доступ

### 1.1 Spotify OAuth
- [ ] Відкрити `/login`
- [ ] Натиснути "Увійти через Spotify"
- [ ] Перевірити redirect до Spotify
- [ ] Увійти в Spotify
- [ ] Перевірити redirect назад до додатку
- [ ] Перевірити що користувач авторизований
- [ ] Перевірити що чат доступний

### 1.2 Protected Routes
- [ ] Спробувати відкрити `/chat` без авторизації
- [ ] Перевірити redirect до `/login`
- [ ] Після авторизації перевірити доступ до `/chat`

---

## ✅ 2. Створення та збереження воркауту

### 2.1 Створення через Settings Panel
- [ ] Відкрити Settings Panel (справа)
- [ ] Встановити параметри:
  - [ ] Тип тренування: "steady"
  - [ ] Тривалість: 30 хвилин
  - [ ] Інтенсивність: "moderate"
  - [ ] HR зони: [110, 150]
  - [ ] Жанри: вибрати "pop", "rock"
  - [ ] Промпт: "Енергійна музика для бігу"
- [ ] Натиснути "Зберегти"
- [ ] Перевірити що воркаут з'явився в історії (зліва, секція "Workouts")
- [ ] Перевірити що всі параметри збережені

### 2.2 Створення через чат
- [ ] Ввести в чат: "легка пробіжка на 30 хвилин"
- [ ] Перевірити що система розпізнала параметри
- [ ] Перевірити що в чаті з'явилося питання: "Сформувати під цей воркаут плейлист? Да чи Ні"

---

## ✅ 3. Активація воркауту з історії

### 3.1 Активація збереженого воркауту
- [ ] Відкрити історію воркаутів (зліва, секція "Workouts")
- [ ] Натиснути на існуючий воркаут
- [ ] Перевірити що:
  - [ ] Параметри завантажилися в Settings Panel
  - [ ] В чаті з'явилася інформація про воркаут
  - [ ] З'явилося питання: "Сформувати під цей воркаут плейлист? Да чи Ні"
  - [ ] Жанри завантажилися
  - [ ] Промпт завантажився

---

## ✅ 4. Генерація плейлисту

### 4.1 Підтвердження створення
- [ ] Після активації воркауту натиснути "Да"
- [ ] Перевірити що система почала генерувати варіанти
- [ ] Перевірити відображення індикатора завантаження

### 4.2 Перегляд варіантів
- [ ] Перевірити що відображаються 2 варіанти плейлисту
- [ ] Перевірити що кожен варіант містить:
  - [ ] Кількість треків
  - [ ] Загальну тривалість
  - [ ] Таблицю з треками (№, Назва, Виконавець, Тривалість)
- [ ] Перевірити що треки не повторюються в межах одного варіанту

### 4.3 Вибір варіанту
- [ ] Натиснути "Обрати цей варіант" на першому варіанті
- [ ] Перевірити що система почала генерувати плейлист
- [ ] Перевірити відображення індикатора завантаження
- [ ] Перевірити що плейлист згенерований
- [ ] Перевірити що плейлист з'явився в історії (зліва, секція "Playlists")

### 4.4 Обробка порожніх варіантів
- [ ] Створити воркаут з некоректними параметрами (наприклад, дуже вузький BPM діапазон)
- [ ] Спробувати згенерувати варіанти
- [ ] Перевірити що відображається помилка якщо обидва варіанти порожні
- [ ] Перевірити що якщо один варіант порожній, він показує "Немає треків у цьому варіанті"
- [ ] Перевірити що кнопка "Обрати цей варіант" недоступна для порожнього варіанту

---

## ✅ 5. Відмова від створення плейлисту

### 5.1 Відмова після активації
- [ ] Активувати воркаут
- [ ] Натиснути "Ні" на питання про створення плейлисту
- [ ] Перевірити що з'явилося повідомлення: "Уточніть ваш запит щодо тренування."
- [ ] Перевірити що можна продовжити діалог

## ✅ 6. Історія плейлистів

### 6.1 Відображення
- [ ] Перевірити що в історії відображаються всі згенеровані плейлисти
- [ ] Перевірити що відображається:
  - [ ] Назва плейлисту
  - [ ] Дата створення
  - [ ] Кількість треків
  - [ ] Посилання на Spotify (якщо є)

### 6.2 Видалення
- [ ] Натиснути "Видалити" на плейлисті
- [ ] Підтвердити видалення
- [ ] Перевірити що плейлист видалений з історії
- [ ] Перевірити що плейлист видалений з бази даних

### 6.3 Динамічне оновлення
- [ ] Згенерувати новий плейлист
- [ ] Перевірити що він автоматично з'явився в історії
- [ ] Зберегти новий воркаут
- [ ] Перевірити що він автоматично з'явився в історії воркаутів
