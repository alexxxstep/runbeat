# Чеклист тестування RunBeat

## ✅ Етап 1: Створення воркаута з промптом

### Тест 1.1: Створення нового воркаута
- [ ] Відкрити панель WorkoutSettings (справа)
- [ ] Встановити тип тренування (наприклад, "Стабільна")
- [ ] Встановити тривалість (наприклад, 30 хв)
- [ ] Встановити інтенсивність (наприклад, "Середня")
- [ ] Встановити ЧСС (наприклад, 110-180)
- [ ] Вибрати жанри музики (наприклад, "Pop", "Rock")
- [ ] **Ввести промпт** (наприклад, "енергійна музика для ранкового бігу")
- [ ] Натиснути "Зберегти"
- [ ] Перевірити, що з'явилося повідомлення "Воркаут успішно збережено!"
- [ ] Перевірити, що воркаут з'явився в панелі "Історія" (зліва) - секція "Воркаути"

### Тест 1.2: Перевірка збереження промпту
- [ ] Перевірити в базі даних (Supabase), що поле `prompt` заповнене
- [ ] Перевірити, що промпт відображається в налаштуваннях після збереження
