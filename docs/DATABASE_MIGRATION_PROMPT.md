# Міграція: Додавання поля prompt до таблиці workouts

## Виконання міграції

1. Відкрийте [Supabase SQL Editor](https://supabase.com/dashboard)
2. Виберіть ваш проект
3. Натисніть **"New query"**
4. Скопіюйте та виконайте SQL з файлу `apps/backend/DATABASE_MIGRATION_ADD_PROMPT.sql`

## Що додається

- **`prompt`** (TEXT) - Текстове поле для додаткового опису побажань користувача до музики

## Використання

Промпт використовується для:
1. **Уточнення пошуку треків** - додається до Spotify Search API запиту
2. **Генерації варіантів плейлистів** - допомагає знайти більш релевантні треки
3. **Збереження контексту** - зберігається разом з воркаутом для повторного використання

## Приклади промптів

- "енергійна музика для ранкового бігу"
- "релаксуючі мелодії для легкого тренування"
- "улюблені треки 2024 року"
- "мотиваційна музика для інтервального тренування"
- "класичний рок для стабільного темпу"

## Технічні деталі

- Промпт передається в `PlaylistGenerateRequest`
- Використовується в `PlaylistGenerator._fetch_for_segment` для додаткового пошуку через Spotify Search API
- Обмеження довжини: 100 символів (для безпеки API запитів)
- Об'єднується з результатами Recommendations API (без дублікатів)
